# StarFall

Unity **6000.6.9f1**，基于 **Universal 3D / URP 空模板**的中世纪魔法生存对局。已接入基础法杖、火宝石、手动瞄准、灵魂吸收，以及元素专属Build和升级三选一。阶段3加入地图障碍、分阶段刷怪、小Boss、关底Boss与通关宝箱；阶段4接通基地、灵魂货币、法杖整备、永久研习与存档。
场景使用纯色几何体：青色球形玩家、棕色法杖与五色宝石、元素弹丸、红色方块敌人、青色泪滴灵魂、深蓝场地。灵魂参照鲁珀特之泪，以圆润头部和细长弯尾区分于玩家。

## 运行

1. 用 Unity 6000.6.9f1 打开本目录，等待包和资源导入。
2. 打开 `Assets/StarFall/Scenes/StarFall.unity`。
3. 点击编辑器 Play，在主菜单选择“新游戏”进入星陨圣所，再点击“进入战场”。已有永久进度自动读取，“新游戏”不清空存档。

主菜单包含新游戏、设置、退出。在编辑器内点击退出会停止 Play Mode。

- **WASD / 方向键**：移动，斜向速度归一化，角色无法离开场地，石墙阻挡玩家、敌人和火球。
- **鼠标**：手动瞄准地面位置，法杖跟随朝向；持续自动施放当前宝石法术，无需点击，无蓝耗，不自动索敌。
- **按住空格**：举起法杖吸收灵魂，可移动和瞄准，但停止施法；松开恢复攻击，不重置射击间隔。已发出的火球继续飞行。
- 敌人死亡掉落 1 点经验灵魂。普通吸取半径 **3**，主动吸取半径 **6.75（3 × 225%）**。灵魂到达玩家时才计入经验，已开始吸附的灵魂不因松开空格停止飞行。
- 灵魂经验达到阈值时，暂停战斗并三选一。鼠标选择，或方向键切换、Enter确认；需先松开吸魂/确认按键及鼠标，避免误选。选完全部待选升级后恢复战斗。
- HUD显示等级、升级经验、已拥有Build数量与魂火层数；暂停菜单显示已获得Build及等级。
- 敌人从场地边缘生成，追击玩家并造成接触伤害；受伤有短暂保护。
- **60秒**出现小Boss，**180秒**出现关底Boss（须先击败小Boss）。击败关底后清场并生成金色宝箱，靠近后按 **E** 获得通关之证并胜利；生命归零失败。结算保存成功后，结果显示 **4 秒**自动返回圣所，也可点击按钮立即返回。
- **Esc**：暂停 / 继续，或关闭设置；暂停菜单可确认中止并返回圣所，保留已收集灵魂。
- 设置提供音量与全屏开关。音量即时生效并保存；全屏用于独立运行窗口，编辑器 Game 视图不切换全屏。

## 调整

配置位于 `Assets/StarFall/Config/`，无需在运行时读取原 Godot 工程：

| 配置 | 当前参数 |
| --- | --- |
| `BaseCharacter.asset` | 生命100、基础移速6、基础灵魂半径3、全元素抗性20% |
| `BasicStaff.asset` | 一个宝石槽、全元素效能100%、灵魂范围225%、移动速度100% |
| `FireGem.asset` | 火球术：基础伤害10、攻击倍率80%、2发/秒、弹速18、射程18 |
| `DefaultBattle.asset` | 180秒关底出现；引用角色、法杖、宝石；敌人生命24、移速2.4、接触伤害10、攻击间隔1秒、全元素抗性0%；掉落、刷怪和上限 |

效能和移动等倍率以 `1 = 100%` 配置，抗性以 `20 = 20%` 配置。距离为 Unity 世界单位，移动/弹道速度为单位每秒。
伤害公式：`Max(1, 基础伤害 × 攻击倍率 × 法杖对应元素效能 × (1 - 目标元素抗性 / 100))`，内部保留小数；零火抗造成8伤害，20%火抗造成6.4伤害。
当前敌人的接触伤害为物理，不受角色的元素抗性减免；改为火元素时会读取角色元素抗性。

首版场地几何体固定为 **42 × 26**；若修改配置中的场地尺寸，需同步调整场景中的 Arena。

角色、敌人、火球、灵魂预制体位于 `Assets/StarFall/Prefabs/`，材质与泪滴网格位于 `Assets/StarFall/Materials/`。
UI 由 `GameUI` 在运行时创建；入口为 `GameApplication`。
规则状态由无 Unity 依赖的 `MatchSession` 管理，`BattleController` 分步推进移动、刷怪、火球、灵魂、受伤和计时。
敌人、火球和灵魂使用对象池；火球使用连续线段命中检测，单体命中即消失，无爆炸或穿透。获得“余烬”后火球附加燃烧，燃烧显示独立橙色火环，保留敌人和Boss原本的识别色。

基地支持基础法杖与引魂法杖免费切换，均携带一颗可切换的元素宝石。提供灵魂仓库、永久研习和本地进度存档；暂不包含精细部件碰撞、复杂动画或游戏构建/发布流水线。
声音为运行时生成的短提示音。中文字体为 Sarasa UI SC，许可见 `Assets/StarFall/Fonts/LICENSE.txt`。

| 灵魂牵引 | 每级主动吸魂倍率+50个百分点，灵魂飞行速度增加基础值20%；不改变普通收集半径 | 2 |
| 灵魂灌注 | 主动吸收每到账1点经验获得1层，最多5层；每次施法消耗1层，火球直接伤害倍率×1.3，不增幅燃烧 | 1 |
| 轻灵步伐 | 每级移动速度增加角色基础值8%，默认每级+0.48 | 3 |
| 魂息回流 | 获得后每累计10点灵魂经验恢复2生命；满血消耗该次治疗，不储存；合并拾取按经验值计数 | 1 |

每级经验消耗依次为 **3、4、5、6、8、10、12**，之后每级再增加4，累计48点经验可以获得7次选择。阈值在 `DefaultBattle.asset` 的 `levelExperience` 中调整；目标是三分钟约5～7次选择，尚未完成整局人工平衡调优。

- 从Lv.1开始，经验溢出保留；一次到账跨越多个等级时逐次选卡。
- 同屏不出现重复卡；满级卡退出卡池。剩余不足3种时显示实际可选数量，不重复补位。
- 卡池按当前主宝石及共鸣筛选；可用强化全部获得后仍记录灵魂经验，不再弹出空卡池。
- 选卡期间计时、移动、敌人、火球、燃烧和灵魂全部冻结，Esc不能绕过选择。重复点击和过期选卡请求不会重复加成。
- 属性加成为基础值加法，不逐级乘算。三级咏唱为3.2发/秒，三级元素亲和为160%效能，三级轻灵步伐为7.44移速；二级灵魂牵引主动半径9.75、灵魂飞行速度12.6。
- 火球生成时记录本次伤害、元素效能和燃烧参数；之后选卡不追溯修改在途火球。燃烧受火效能及火抗影响，每秒结算一次；魂火只增强直接伤害。
- 获得Build前的经验不追溯触发魂火或治疗。每局的Build、生命上限加成、魂火、治疗余数、燃烧状态和升级进度均在重新开局时清空。

卡片名称、说明与等级上限位于 `BuildCatalog.cs`；抽取与等级进度位于 `BuildProgression.cs`，效果由 `MatchSession` 和 `BattleController` 接入。

## 阶段3：地图与完整对局

- 不设置撤离阶段。完整流程为怪群 → 小Boss → 关底Boss → 清场 → 开宝箱 → 通关之证 → 结算。
- 地图使用4块蓝灰色石墙，配置以世界XZ中心与宽深记录。角色沿墙滑动；敌人按自身半径使用网格寻路绕障；火球在墙体或边界处消失，无法隔墙攻击。
- 0～60秒普通怪上限12，60～120秒上限20，120秒后上限30，均不超过配置maxEnemies。生成间隔按这三个阶段由1.2秒递减至0.45秒；Boss独立生成，不受普通怪上限阻止。关底出现后停止生成普通怪。
- 小Boss为金橙色大方块：生命120、速度1.9、半径1，击杀掉落一颗价值6经验的灵魂。小Boss未死时，即使超过180秒也不会跳过它。
- 关底Boss为紫色巨型方块：生命360、速度1.4、半径1.5、火抗20%。基础火球每次造成6.4伤害，可受已有Build增幅。
- Boss每5秒发动范围攻击：小Boss单圈物理砸击18伤害；关底在目标与左右位置生成三个火圈，每圈基础火伤25，受到玩家元素抗性减免。半径2，先预警1.4秒，后两个火圈依次延后0.3秒；位置在预警时锁定，可以移出范围躲避。共享玩家受伤保护，预警在暂停及选卡时冻结。
- 击败关底立即停止战斗，所有存活怪计入击杀并清除，不额外掉经验；火球、预警及未拾取灵魂一并清除，避免领奖阶段触发升级。金色宝箱出现在关底死亡处。
- 领奖阶段可移动、暂停和返回菜单，停止攻击与吸魂，战斗计时冻结。距离宝箱2单位以内且无遮挡时按E；通关之证仅本局发放一次，发放后才进入胜利结算；阶段4起将通关之证累计保存到基地仓库。
- 新行动重置Boss、宝箱、本局证明状态、预警和所有局内Build；仓库中累计的证明与永久研习保留。配置集中在DefaultBattle.asset。

## 阶段4：星陨圣所与永久成长

主菜单 → 星陨圣所 → 法杖整备 / 永久研习 → 进入战场 → 结果 → 圣所。基地采用简化界面，提供灵魂余额、通关之证数量和上次行动报告，不需要移动角色寻找设施。

### 灵魂货币

- 实际吸收到玩家的灵魂价值，同时计入局内经验与本局货币收益。经验升级不会消耗这笔货币，也不会用等级经验余数结算。
- 胜利、阵亡、主动中止均全额保留已收集灵魂；地上未拾取的灵魂不计收益。关底清场不额外发钱，通关之证独立记录。
- 每次拾取后持久化本局累计数量；结束时一次性入库。每局拥有唯一行动ID，防止结果重试、重复返回、重新读取时重复发奖。
- 崩溃或直接停止Play后，下次启动将最近成功保存的本局数量按“中断返还”入库；不恢复战斗现场。
- 保存失败时冻结战斗或停留结果页，显示重试；保存成功前不自动返回、不能开始下一局。基地升级失败不扣款、不增加等级。

### 装备与研习

两把法杖初始免费开放，均为单宝石槽、移速100%、可选择五种宝石之一：

| 法杖 | 全元素效能 | 主动吸魂范围倍率 |
| --- | --- | --- |
| 基础法杖 | 100% | 225% |
| 引魂法杖 | 85% | 300% |

三项永久研习均为Lv.0～5，各级费用依次20、35、55、80、110灵魂，每条升满共300灵魂。购买前显示确认，默认选中取消。

| 研习 | 每级效果 | 满级基础结果 |
| --- | --- | --- |
| 生命研习 | 最大生命+10 | 150生命 |
| 元素研习 | 全元素效能+5个百分点 | 基础法杖125%，引魂法杖110% |
| 引魂研习 | 角色基础吸魂半径+0.2 | 普通半径4；基础法杖主动9，引魂法杖主动12 |

永久加成在出击时快照，与局内Build加法叠加。局内强健体魄仍每级+20生命，元素亲和每级+20个百分点；灵魂牵引加在法杖主动倍率上。例：一级引魂研习+引魂法杖主动半径为3.2×300%=9.6。战斗中不能更换法杖或购买永久升级。新行动清空局内Build、灵魂层数与经验，保留永久等级和仓库余额；不修改原始ScriptableObject数值。

数值与价格集中在`PermanentRules`（`PermanentProgress.cs`），为首轮可玩参数，未完成长期经济平衡。只迁移当前魔法玩法需要的成长；不引入旧枪械、材料货币和撤离回收机制。

## 五元素与共鸣体验版（2026-11-20）

### 最快体验方法

打开`Assets/StarFall/Scenes/StarFall.unity`并Play。主菜单右侧点击 **宝石整备 / 快速体验**，选择宝石和兼容共鸣，再点击 **60秒快速试炼** 或 **直接挑战Boss**。基地也有“选择宝石 / 共鸣试验”入口。

快速试炼使用基础属性，默认开启无敌，15秒小Boss、60秒关底；仍须先击败小Boss再进入关底。测试期间击杀、灵魂、免费升级和通关之证都不写入永久仓库，也不覆盖上次正式行动报告。装备面板的宝石选择会正常保存；战斗中快捷切换只影响本次测试。

| 快捷键 | 功能 |
| --- | --- |
| 1 / 2 / 3 / 4 / 5 | 切换火焰 / 雷电 / 风 / 海洋 / 大地，并重新开局 |
| R | 当前宝石与预装共鸣重新开局，清空局内升级与怪物 |
| U | 免费打开一次升级三选一，不产生灵魂货币 |
| C | 循环兼容共鸣 / 无共鸣，并重开本局 |
| B | 战斗进行时直接进入关底Boss，保留当前构筑 |
| I | 切换无敌 / 正常受伤 |
| Esc | 暂停；暂停后可返回圣所 |

这些操作也有屏幕顶部按钮。切换宝石、共鸣和重开会清空本局Build；默认无敌开关在重开时保留。测试胜负后停留结果页，可R重试或点击返回圣所，不自动退出。正常出击不显示测试工具、不启用无敌，仍为60秒小Boss、180秒关底，正常保存收益。

### 双向共鸣与组合大招

- **火＋雷 / 天罚烙印**：瞄准方向锁定敌人，0.65秒刻印蓄势后落雷，周围同时遭受雷击、火焰与燃烧；刻印期间直接命中可增强落雷，最多增加24点基础伤害。紫色雷柱、旋转符文阵和橙色冲击环。
- **火＋风 / 焚风龙卷**：向瞄准方向推进的火焰龙卷，拉扯附近敌人，每0.35秒造成火与风伤害并施加燃烧。火主持续4.4秒，风主移动更快、持续3.8秒。多层火焰螺旋、金色余烬和青绿风带。
- **风＋海洋 / 深海涡旋**：在鼠标方向最多12单位处形成半径3.5的涡旋，聚怪、减速和持续海洋伤害；3.2秒后沿施法方向推出浪墙，每名敌人只受一次浪击。风主吸力更强，海洋主减速更强。蓝绿螺旋汇聚后出现宽幅月牙浪墙。
- **海洋＋大地 / 泥沼**：保留原机制，每第三次施法首次命中生成半径2、持续2.5秒的泥沼，减速并在持续停留后禁锢。

前三组替换原火雷、火风的小型共鸣效果，并新增风海洋。普通攻击命中积累组合能量，同轮风刃、范围命中只算一次，基础持续命中约6秒充满；未命中、燃烧和组合伤害不充能。满能量后下一次普通施法自动释放，空格吸魂期间保留能量。天罚需瞄准范围内可见敌人，其他组合需瞄准场内；画面下方显示能量。Boss受拉扯和浪击位移大幅降低。

每局只绑定一个共鸣元素，不占实体宝石槽，不自动生成第二套主攻击。正式升级前两次无共鸣卡，第三次保证至少一个兼容共鸣选项；未选择时之后仍可随机出现，第六次再次保证提供。选择后其他共鸣退出卡池。试炼可直接预装或用C切换；未实现的组合在面板标为未开放。

范围攻击、连锁、组合技能与泥沼均检查障碍遮挡。风刃穿透有次数和衰减，单枚不重复命中同一敌人；弱减速不能延长强减速持续时间。暂停与选卡冻结状态及特效；关底清场、重开和退出会清除延迟区域与效果。影响特效采用纯色几何和复用池，仍非最终美术。
